# notes/

Drop plain-text or markdown files here — the mirror indexes them into its
memory alongside your spoken notes and past conversations. Ask things like
"what did I write about the apartment?" or "have I noted anything about taxes?".

Files are split by paragraph, timestamped by last-modified, and re-indexed
within ~10 minutes of a change (or immediately via `POST /api/memory/reindex`).

This file and the folder are gitignored except this example.
